[size=4][b]Was ist Anvil?[/b][/size]

MO2 dominiert auf Windows — Anvil füllt die Lücke auf Linux.

Komplett neu geschrieben mit Python und PySide6 (Qt6). Kein Wine, kein Proton-Wrapper, keine Workarounds. Anvil nutzt physische Symlinks statt eines virtuellen Dateisystems. Dein Spielverzeichnis bleibt sauber.

Anvil ist [b]kein[/b] Fork oder Port von MO2. Jede Zeile Code wurde von Grund auf geschrieben — aber der Workflow fühlt sich sofort vertraut an für jeden, der MO2 kennt.

[size=4][b]Offenes Plugin-System[/b][/size]

Anvil hat ein offenes Plugin-System — jeder kann neue Games hinzufügen. Ein Game-Plugin ist nur eine einfache Python-Datei mit ein paar Attributen. Kein Framework-Wissen nötig.

[code]class ValheimGame(BaseGame):
    GameName = "Valheim"
    GameBinary = "valheim.exe"
    GameDataPath = ""
    GameSteamId = 892970[/code]

Das war's. Datei in den Plugins-Ordner legen, Anvil neustarten, fertig. Genau wie bei MO2's basic_games System.
