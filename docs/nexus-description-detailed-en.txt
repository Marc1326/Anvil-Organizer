[size=4][b]What is Anvil?[/b][/size]

Anvil Organizer is a native mod manager for Linux. Built with Python and Qt6, it runs directly on your system — no Wine, no Proton wrapper, no workarounds.

Anvil uses physical symlinks instead of a virtual file system. Your game directory stays clean. Mods are deployed on launch and removed on exit.

Over 30 games are supported — including Cyberpunk 2077, Baldur's Gate 3, Skyrim SE, Fallout 4, Elden Ring, Starfield, Witcher 3 and Red Dead Redemption 2. Thanks to the open plugin system, anyone can add new games.
